# models

- [`local/archetypes/`](local/archetypes/): the archetypes this repository authors, ADL 1.4, one folder per class as in the openEHR CKM mirror (`demographic/`, `ehr_status/`, `folder/`). Generated by [`tools/generator`](../tools/generator/); do not edit them by hand.
- [`remote/org.openehr/`](remote/org.openehr/): published openEHR CKM archetypes the templates embed, vendored unmodified as CKM exports them (ADL and XML), each pinned by sha256 in `MANIFEST.txt`. Refresh with `make sync`.
