# tech/templates

One folder per template, named by its template id, holding the operational template (OPT 1.4 XML) in `opt/{template-id}.opt`.
The OPTs are generated by [`tools/generator`](../../tools/generator/); do not edit them by hand.
A folder may later hold a template's example instances (`instances/`) and generated documentation (`exports/`), as in the freshEHR project layout.
