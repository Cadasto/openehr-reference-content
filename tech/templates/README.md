# tech/templates

One folder per template, named by its template id, holding the operational template (OPT 1.4 XML) in `opt/{template-id}.opt` and an example instance in canonical JSON in `instances/{template-id}.json`.
The OPTs are generated by [`tools/generator`](../../tools/generator/) (`make generate`), the examples with openehr-sdk-go (`make examples`); do not edit either by hand.
An example is the instance the SDK generates from the template under its default policy, with example values.
The SDK leaves out an ITEM_TREE a template leaves open, so the examples of `generic_ehr_status.v1` and `generic_folder.v1` add a plain one as their details, to show them.
The SDK's example values make an EHR_STATUS neither queryable nor modifiable, so its example sets both to true, the values of the default EHR_STATUS in the openEHR REST API's `POST /ehr`.
A folder may later hold generated documentation (`exports/`), as in the freshEHR project layout.
